# Global Architecture Decision Records (ADR)

Use this directory for decisions that affect the system across initiatives.

- Initiative-specific decisions belong in `../prd/prd-xxx/decisions/`.
- Cross-system decisions belong here.
- Accepted decisions are append-only historical records; supersede them with a new ADR rather than silently rewriting
  rationale.

Use the ADR template in `../templates/` when creating a new record.
