# API Error Codes

| Code                         | HTTP | Meaning                                                                                                          | Client behavior                                                                        |
|------------------------------|-----:|------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------|
| `VALIDATION_ERROR`           |  400 | Request field validation failed                                                                                  | Show field-level errors                                                                |
| `INVALID_AUDIENCE_RULE`      |  400 | Unsupported field/operator/value or malformed rule document                                                      | Highlight invalid audience condition                                                   |
| `UNAUTHENTICATED`            |  401 | No valid access session                                                                                          | Redirect to login or refresh flow                                                      |
| `TOKEN_EXPIRED`              |  401 | Access token expired                                                                                             | Attempt one refresh, then re-authenticate                                              |
| `FORBIDDEN`                  |  403 | Role or resource permission denied                                                                               | Show access-denied state                                                               |
| `CSRF_INVALID`               |  403 | Missing/invalid CSRF token                                                                                       | Refresh CSRF token and retry once where safe                                           |
| `RESOURCE_NOT_FOUND`         |  404 | Resource does not exist or is not visible                                                                        | Show not-found state                                                                   |
| `CAMPAIGN_CONFLICT`          |  409 | Draft-only message/campaign write or invalid campaign lifecycle transition                                       | Refresh campaign detail; only drafts are editable                                      |
| `CAMPAIGN_NOT_PUBLISHABLE`   |  409 | Campaign is not a valid draft, required setup is missing, or the campaign is outside its publishable time window | Show setup validation summary                                                          |
| `CAMPAIGN_INACTIVE`          |  409 | Campaign is paused, ended, or outside active window                                                              | Disable claim action and explain                                                       |
| `DELIVERY_JOB_NOT_RETRYABLE` |  409 | Delivery job is not in `FAILED` state                                                                            | Show current job status; retry is available only after failure                         |
| `MEMBER_NOT_ELIGIBLE`        |  409 | Member is not in the publication audience snapshot                                                               | Show unavailable message without disclosing audience rules                             |
| `COUPON_OUTSIDE_VALIDITY`    |  409 | Coupon is outside its configured validity window                                                                 | Disable claim action                                                                   |
| `COUPON_SOLD_OUT`            |  409 | No remaining coupon inventory                                                                                    | Show sold-out state                                                                    |
| `CLAIM_ALREADY_EXISTS`       |  409 | Member already claimed this campaign coupon                                                                      | Show already-claimed state                                                             |
| `IDEMPOTENCY_KEY_CONFLICT`   |  409 | Same idempotency key reused for a different request                                                              | Do not retry with that key; create a new request key only for a new intent             |
| `RATE_LIMITED`               |  429 | Request rate limit reached, if configured                                                                        | Back off and retry only when appropriate                                               |
| `ANALYTICS_INTEGRITY_ERROR`  |  500 | Coupon inventory counter disagrees with successful claim rows; report is withheld until data is reconciled       | Show a generic integrity warning and trace ID; do not display inconsistent report data |
| `INTERNAL_ERROR`             |  500 | Unexpected server error                                                                                          | Show generic error and trace ID                                                        |

All errors use the common response envelope in `API_SPECIFICATION.md`. The server may return more detailed validation
fields but must not disclose internal stack traces or sensitive data.
